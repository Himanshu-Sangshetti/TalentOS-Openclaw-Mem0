# Security

## Reporting vulnerabilities

If you find a security issue, please report it responsibly:

- **Do not** open a public issue.
- Contact the maintainers privately (e.g. via the repository’s About or maintainer list) with a clear description and steps to reproduce.
- We will acknowledge and work on a fix; we may ask for more detail.

## Scope

- This project: OpenClaw plugin (TalentOS), optional view server, tests, and docs.
- Out of scope: OpenClaw, Mem0, or third-party services; please report those to their respective projects.

# Contributing

Contributions are welcome: bug fixes, docs, and small features that fit the scope (see [ARCHITECTURE](docs/ARCHITECTURE.md)).

## How to contribute

1. Open an issue to discuss bugs or features.
2. Fork the repo, create a branch, make changes. Keep commits focused.
3. Run `npm run test`, `npm run lint`, and `npm run typecheck`.
4. Open a pull request with a short description and link to the issue.

By contributing, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
